# ACZ7015 XDMA Linux 部署文档

## 概述

本文档指导如何在新 ACZ7015（Zynq7015）开发板上部署 XDMA PCIe + PS侧Linux + USB鼠标数据采集系统。

**系统架构**：
```
USB鼠标 → ACZ7015(PS侧Linux) → PCIe/XDMA → Windows PC(上位机)
```

**协议标准**：32字节统一槽位格式（详见 [docs/protocol_spec.md](../docs/protocol_spec.md)）

---

## 前置条件

### 硬件
- ACZ7015 开发板（Zynq XC7Z015）

- Windows PC（带 PCIe 插槽）

## 阶段1：SD卡准备

### 1.1 烧录原厂镜像

**烧录工具**：[部署/工具/Win32DiskImager/Win32DiskImager.exe](工具/Win32DiskImager/Win32DiskImager.exe)（绿色版，免安装，直接运行）

1. 解压 `ACZ7015_ubuntu_desktop.zip` 得到 `.img` 文件
2. 运行 `部署/工具/Win32DiskImager/Win32DiskImager.exe`
3. 选择 `.img` 文件，选择 SD 卡盘符，点击写入

### 1.2 替换启动文件

SD卡 FAT32 分区替换为仓库中的文件（[部署/启动文件/](启动文件/)）：

| 仓库文件 | SD卡目标文件 | 说明 |
|----------|--------------|------|
| `BOOT.BIN` | `BOOT.BIN` | u-boot 引导（可选，原厂即可） |
| `SYSTEM_xdma.bit` | `system.bit` | XDMA bitstream（3.35MB） |
| `SYSTEM_xdma.dtb` | `system.dtb` | 改造设备树（禁用11个PL节点+USB Host模式） |
| - | `uEnv.txt` | 见下方内容，手动创建 |

**uEnv.txt 内容**（无BOM头）：
```
bootargs=console=ttyPS0,115200 root=/dev/mmcblk0p2 rw earlyprintk rootfstype=ext4 rootwait devtmpfs.mount=0
loadbit_addr=0x100000
bitstream_size=0x400000
```

> ⚠️ `bitstream_size` 必须为 `0x400000`（4MB），原厂 `0x300000` 不够装 3.35MB 的 XDMA bitstream

### 1.3 设置启动模式

- `MIO[5]=1, MIO[4]=0`（SD卡启动）
- **必须断电操作！**

## 阶段2：开发板启动

### 2.1 上电启动
1. 插入 SD 卡，上电
2. 等待 Linux 启动（约 30-60 秒）
3. 串口/SSH 连接确认

### 2.2 确认USB鼠标设备
```bash
cat /proc/bus/input/devices | grep -A6 "Usb Mouse"
# 找 Handlers=eventX 的 X 值（可能是 0/1/2）
```

### 2.3 确认网络
```bash
ifconfig  # 记录 IP（如 172.20.33.xxx）
```

### 2.4 WiFi自动连接（可选）
已配置开机自启，如需修改：
```bash
sudo nano /etc/wpa_supplicant.conf  # 改 SSID/密码
sudo /etc/init.d/wifi-connect.sh restart
```

## 阶段3：PS端部署

### 3.1 传输程序到开发板

**方法A：SCP传输（PC执行）**
```powershell
scp linux/arm_apps/arm_mouse_sender zynq@开发板IP:~/
```

**方法B：部署脚本（自动编译运行）**
```powershell
python 部署/脚本/deploy_ps.py  # 改IP后执行
```

### 3.2 编译（如需）
```bash
gcc -O2 -o arm_mouse_sender arm_mouse_sender.c
```

### 3.3 运行
```bash
# 查看帮助
./arm_mouse_sender --help

# 运行（用实际event设备号）
sudo ./arm_mouse_sender /dev/input/event0
```

看到 `等待鼠标事件...` 即就绪。

## 常见问题

### Q1: PC端 ReadFile 阻塞
**原因**：XDMA DMA引擎卡死（PS端写DDR+PC端DMA读冲突）
**解决**：
1. 设备管理器 → 禁用XDMA设备 → 启用
2. 或开发板断电重启（重新加载bitstream+PCIe训练）

### Q2: event1 不是鼠标
**原因**：event1 可能是 gpio-keys（板载按键），不是USB鼠标
**解决**：用 `cat /proc/bus/input/devices` 找 `Handlers=eventX` 的鼠标设备

### Q3: XDMA test 卡住
**原因**：XDMA AXI-ST design，DMA引擎异常
**解决**：开发板断电重启 + PC端禁用/启用XDMA设备

### Q4: uEnv.txt syntax error
**原因**：PowerShell默认加BOM头
**解决**：用 `Set-Content -Encoding ASCII` 或 .NET `File.WriteAllText`

### Q5: WiFi 连不上
**原因**：rtl8188fu 仅支持 wext 接口
**解决**：`wpa_supplicant -D wext`（不是 nl80211）

# ACZ7015 XDMA工程 集成CAN/CANFD/RS485模块

## 目标
在现有XDMA工程基础上，集成小梅哥ACM_CANFD_RS485模块，实现CAN/RS485通信，同时保持XDMA PCIe功能不变。

## 资源评估（已确认可行）

### XDMA工程资源占用
| 资源 | 占用 | 可用 | 利用率 | CAN模块需求 |
|------|------|------|--------|------------|
| Slice LUTs | 14,086 | 46,200 | 30.49% | ~100 |
| Slice Registers | 15,998 | 92,400 | 17.31% | ~50 |
| Block RAM | 20.5 | 95 | 21.58% | 0 |
| DSP | 0 | 160 | 0% | 0 |
| 实际IOB | 3 | 150 | 2% | ~14引脚 |

**结论**：资源充足，完全可以合并。

## 模块架构

```
ACZ7015 PS侧                  PL侧引脚(JE/JF扩展口)         CAN模块
┌──────────┐   ┌──────────────────────────┐   ┌────────────────┐
│ PS SPI0  │→→│ SPI0_SCLK(G6)            │→→│ MCP2518FD      │
│ (XSPIPS) │→→│ SPI0_MOSI(F6) SPI0_MISO(H1)│←→│ (CANFD芯片)    │
│          │→→│ SPI0_SS(G1)              │→→│                 │
├──────────┤   ├──────────────────────────┤   ├────────────────┤
│ PS GPIO  │→→│ GPIO_0[0-7](G3/C1等8引脚)│→→│ INT/RS485_RE   │
│ (XGPIOPS)│   │                          │   │                 │
├──────────┤   ├──────────────────────────┤   ├────────────────┤
│ PS UART1 │→→│ UART_1_TX(F5) RX(E5)     │→→│ RS485收发器    │
│ (XUARTPS)│   │                          │   │                 │
└──────────┘   └──────────────────────────┘   └────────────────┘
```

## 引脚分配

### SPI0（GPIO0_0_tri_io[10-13]）
| 信号 | PACKAGE_PIN | GPIO编号 | 功能 |
|------|-------------|----------|------|
| SPI0_SCLK_O | G6 | GPIO0_0[10] | SPI时钟 |
| SPI0_MOSI_O | F6 | GPIO0_0[11] | SPI主出 |
| SPI0_MISO_I | H1 | GPIO0_0[12] | SPI主入 |
| SPI0_SS_O | G1 | GPIO0_0[13] | SPI片选 |

### GPIO EMIO 8位（GPIO0_0_tri_io[14-21]）
| GPIO bit | PACKAGE_PIN | 功能 |
|----------|-------------|------|
| 0 | G3 | INT0_0（CAN0中断）|
| 1 | G2 | INT1_0 |
| 2 | F2 | CAN_INT_0 |
| 3 | F1 | INT1_1 |
| 4 | E4 | INT0_1 |
| 5 | E3 | CAN_INT_1 |
| 6 | D1 | RS485A_RE（接收使能）|
| 7 | C1 | RS485B_RE（接收使能）|

### UART1（GPIO0_0_tri_io[22-23]）
| 信号 | PACKAGE_PIN | 功能 |
|------|-------------|------|
| UART_1_TX_O | F5 | RS485串口发送 |
| UART_1_RX_I | E5 | RS485串口接收 |

## 操作步骤

### 步骤1：修改Block Design（Vivado GUI）
1. 打开 `G:\fpga\0708\0810\xdma\xdma\xdma.xpr`（XDMA工程）
2. 在Tcl Console执行：
   ```tcl
   cd d:/workspace/trae/day01/0702/acz7015-xdma-linux/fpga/can_integration
   source integrate_can.tcl
   ```
3. 确认Block Design里SPI0/UART1/GPIO的EMIO引脚已引出到外部端口
4. 如果没有自动引出，在BD里右键PS7 → Make External

### 步骤2：添加引脚约束
1. Add Sources → Add Constraints → 添加 `can_module.xdc`
2. 确认所有引脚都已分配

### 步骤3：重新综合实现
1. Run Synthesis
2. Run Implementation
3. Generate Bitstream

### 步骤4：导出硬件
1. File → Export Hardware（含bitstream）
2. 导出HDF给SDK

### 步骤5：更新设备树
需要在设备树里添加SPI0/UART1的设备节点（CAN驱动使用socketcan）

### 步骤6：物理连接
- CAN模块插到ACZ7015的JE/JF扩展口
- 对应引脚：SPI0/GPIO/UART1的PL引脚

## 风险评估

### 低风险
- **PL资源**：LUT占用从30%增到31%，影响极小
- **PS SPI驱动**：复用小梅哥例程代码，成熟稳定
- **引脚分配**：GPIO0_0[10-23]当前未用，无冲突

### 中风险
- **EMIO引脚名**：Vivado自动生成的EMIO引脚名可能与XDC不完全匹配，需在GUI确认
- **设备树**：需添加SPI0/UART1的设备节点，可能影响内核启动

### 待确认
- **GPIO方向**：EMIO的GPIO_0_tri_o（输出）和GPIO_0_tri_i（输入）共用引脚，XDC需同时约束
- **UART0 vs UART1**：UART0保持MIO调试，UART1用EMIO给RS485，需确认模块接线

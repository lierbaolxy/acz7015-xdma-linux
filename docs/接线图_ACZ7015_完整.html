施工注意事项

1. 差分线必须交叉：球壳丝印的 R/T 是球自身视角，所以「球的 R+（21）接模块 T+」「球的 T+（22）接模块 R+」。若完全不通，先把 21/22 与 23/24 两对整体对调。
2. 继电器 VCC 只能 3.3V：线圈是 SRD-03VDC-SL-C（3V），接 5V 会烧。实际接线取 GPIO1（P9）pin29 = 3.3V、pin30 = GND。GPIO0 pin29 已被编码器 3.3V 占用，不要再从那里取电。继电器 IN 必须回 GPIO0 pin35（GPIO1 上没有 E8）。
3. XS1-25/26 只接继电器 COM/NO：不接电源，也不要与 XS1-6（MENU 按键）并联。
4. 按键顺序不是 37/38/39/40：必须按 XS1-5→pin39、6→pin40、7→pin37、8→pin38 接，否则按键功能错位。
5. GPIO0 pin26 / pin28 悬空：原 UART1 EMIO 方案已废弃，不要再接任何东西。
6. 两路 GND 都要接：pin12→XS1-27、pin30→XS1-29，保证回流可靠。
7. 认准排针丝印：GPIO0 = P7（板卡 Type-C 旁），GPIO1 = P9（按键旁）。两组排针针号相同但功能不同，插线前对着丝印确认，不要把两个 pin29 当成同一个 3.3V 直接串接。
上电前用万用表核对：pin29 对 GND 约 3.3V，pin11 对 GND 约 5V，pin35 静态为低（继电器不吸合）；8 路信号对 5V / 3.3V 无短路。上电静置 1 分钟，继电器不应误吸合。

## 四、DDR共享内存布局

```
DDR物理地址空间 (reserved-memory 512MB)
┌─────────────────────────────────────────────────────────────────┐
│ 0x00000000 ───────────────────────────────────────── 0x1FFFFFFF │
│            Linux 系统使用区域 (512MB)                           │
├─────────────────────────────────────────────────────────────────┤
│ 0x20000000 ───────────────────────────────────────── 0x3FFFFFFF │
│            XDMA DDR 共享内存区域 (512MB)                        │
│                                                                 │
│  0x20000000 ┌─────────────────────────────────────┐            │
│             │ USB 槽位 (32字节)                    │            │
│             │ {seq,dev_id=0,dlen,res,data[8],ts}    │            │
│  0x20000020 ├─────────────────────────────────────┤            │
│             │ CAN 槽位 (32字节, 预留)              │            │
│             │ {seq,dev_id=1,dlen,res,data[8],ts}    │            │
│  0x20000040 ├─────────────────────────────────────┤            │
│             │ PS2 槽位 (32字节, 预留)              │            │
│             │ {seq,dev_id=2,dlen,res,data[8],ts}    │            │
│  0x20000060 ├─────────────────────────────────────┤            │
│             │ RS422 槽位 (32字节, 预留)            │            │
│             │ {seq,dev_id=3,dlen,res,data[8],ts}    │            │
│  0x20000080 ├─────────────────────────────────────┤            │
│             │ ... (后续数据区)                     │            │
│             └─────────────────────────────────────┘            │
└─────────────────────────────────────────────────────────────────┘
```

### 32字节统一槽位格式

```
偏移   字段        大小    说明
─────────────────────────────────────────────────
0x00   seq        4字节   序列号（PC端检测变化）
0x04   device_id  4字节   设备ID(0=USB/1=CAN/2=PS2/3=RS422)
0x08   data_len   4字节   有效数据长度
0x0C   reserved   4字节   保留字段
0x10   data[8]    8字节   数据内容
0x18   tv_sec     4字节   时间戳-秒
0x1C   tv_nsec    4字节   时间戳-纳秒
─────────────────────────────────────────────────
       合计       32字节  (对齐cache line)
```

## 六、关键参数速查

| 参数 | 值 | 说明 |
|------|------|------|
| **PCIe** | Vendor=10ee, Device=7021 | Xilinx XDMA |
| **DDR共享基址** | 0x20000000 | reserved-memory |
| **DDR共享大小** | 512MB | 0x20000000-0x3FFFFFFF |
| **槽位大小** | 32字节 | 对齐cache line |
| **槽位间隔** | 0x20 | 4路接口各占一槽 |
| **USB鼠标设备** | /dev/input/event0 | SIGMACHIP Usb Mouse |
| **PC端设备节点** | c2h_0 | Card to Host (PC读DDR) |
| **DMA读取大小** | 64字节 | XDMA对齐要求(解析前32字节) |
| **单程延时** | 400-700us | USB中断+Linux+DDR+XDMA |
| **bitstream大小** | 3,510,780字节 | SYSTEM_xdma.bit |
| **uEnv bitstream_size** | 0x400000 | 必须≥3.35MB |
| **SSH连接** | zynq@172.20.33.225 | 密码: root |

## 七、四路接口规划

```
            ┌─────────────────────────────────────────┐
            │         ACZ7015 采集卡                   │
            │                                         │
  USB ──────┤  USB Host (event0)  ──┐                │
  (已实现)  │  device_id=0          │ 槽位@0x20000000│ ──▶ PCIe ──▶ PC
            │                       │                │
  PS2 ──────┤  USB转PS2模块(阶段1)  │ 槽位@0x20000040│
  (规划)    │  device_id=2         │                │
            │                       │                │
  CAN ──────┤  PL axi_can+PHY(阶段2)│ 槽位@0x20000020│
  (规划)    │  device_id=1          │                │
            │                       │                │
  RS422─────┤  PL axi_uartlite(阶段2)槽位@0x20000060│
  (规划)    │  device_id=3          │                │
            └─────────────────────────────────────────┘

阶段1（当前）：USB + PS2（PS2用USB转PS2模块插USB口）
阶段2（后续）：CAN + RS422（需PL侧添加IP+外接PHY/收发器）
```
